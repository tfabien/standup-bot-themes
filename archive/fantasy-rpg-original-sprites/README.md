# Original Fantasy RPG sprites

The original detailed PNG sprites are preserved here. The active theme uses a simplified chunky pixel-art set with five complete teams selected through `look.sprite`.

`sprite-sheet-core-palettes.png` contains the Humans and Dark teams. `sprite-sheet-elves.png` contains the redrawn Elves. `sprite-sheet-orcs-goblins.png` contains the Orc and Goblin teams. They are the transparent production sheets used to crop the active 40 sprites. `sprite-sheet-source.png` preserves the first three-team draft.
